# Changelog

## v1.3.3 — Initial public source release

- Published an institution-neutral Apps Script Gmail inbox firewall and contextual Gmail add-on.
- One-click **Block this conversation** with DRY_RUN preview and safety checks across the selected conversation.
- Persistent reply-lineage memory, including later replies incorrectly labeled KEEP, while preserving protected admission-test and invigilation duty responses.
- Optional Workspace Studio classifier plus conservative free on-account rule-based fallback.
- Private Google Sheets Audit, Pending, BlockedKeys and AllowedKeys; compact collapsible Gmail labels with red `ZZ/AF_N` noise chip.
- Updated custom shield/envelope icon and setup instructions.
- Source fixtures use fictitious `example.edu` accounts and do not depend on any institution-specific mailing domain.

This initial public tag does not imply a production certification. Local automated tests simulate the Google APIs; the add-on must be tested in each user's Workspace environment.
